## 内容概览

## 基础篇：STM32 外设与开发流程

### 1. 芯片、开发板与工程环境

- 了解 ARM 内核和 STM32 的基本概念、应用场景及系列命名规则。
- 认识寄存器开发、HAL 库开发等 STM32 开发方式。
- 使用 Keil MDK、STM32CubeMX、ST-LINK 和 VSCode 等工具。
- 了解开发板、核心板、扩展板和 STM32 最小系统。
- 创建、配置、编译、下载和调试第一个 STM32 工程。

### 2. GPIO 与寄存器

- 理解 GPIO 的输入、输出、复用和模拟等工作模式。
- 掌握 GPIO 端口配置和输入输出数据寄存器。
- 了解 `GPIOx_CRL`、`GPIOx_CRH`、`GPIOx_IDR`、`GPIOx_ODR`、`GPIOx_BSRR`、`GPIOx_BRR` 和 `GPIOx_LCKR`。
- 通过寄存器方式实现流水灯。
- 使用 Keil 与 VSCode 优化嵌入式开发体验。

### 3. 系统架构与时钟

- 了解 STM32 的总体架构。
- 理解时钟树及不同系统时钟的作用。
- 为外设初始化和定时功能建立时钟基础。

### 4. HAL 库开发

- 理解 HAL 库的作用和开发模式。
- 安装 Java 环境、STM32CubeMX 和芯片支持包。
- 使用 STM32CubeMX 生成 HAL 工程。
- 通过 HAL 库实现 LED 流水灯，并理解自动生成代码和用户代码的组织方式。

### 5. 中断

- 理解中断的概念、作用和处理流程。
- 了解 STM32 中断体系、NVIC 和外部中断控制器。
- 对比寄存器方式和 HAL 库方式的中断配置。
- 通过按键检测案例理解 GPIO 外部中断。

### 6. USART 串口通信

- 区分并行通信、串行通信、单工、半双工、全双工、同步和异步通信。
- 理解串口通信协议和 USART 外设。
- 使用轮询方式和中断方式接收串口数据。
- 实现计算机与 STM32 的串口通信。
- 重定向 `printf`，建立嵌入式调试输出通道。

### 7. I2C 通信

- 理解 I2C 总线基础知识和操作时序。
- 通过 M24C02 存储器案例学习软件模拟 I2C。
- 使用 STM32 I2C 外设实现硬件 I2C。
- 分别使用寄存器和 HAL 库完成设备读写。

### 8. 定时器

- 了解 SysTick、基本定时器、通用定时器和高级定时器。
- 使用系统定时器和基本定时器实现 LED 闪烁。
- 使用 PWM 实现 LED 呼吸灯。
- 测量 PWM 的频率、周期和占空比。
- 输出有限个周期的 PWM 波形。

### 9. DMA

- 理解 DMA 的作用、框图和数据传输过程。
- 实现 ROM 到 RAM 的数据传输。
- 实现 RAM 到串口等外设的数据传输。
- 对比寄存器方式和 HAL 库方式的 DMA 配置。

### 10. ADC

- 理解 ADC 和逐次逼近型 ADC 的工作原理。
- 使用 STM32 ADC 外设进行单通道采集。
- 实现独立模式下的多通道采集。
- 结合寄存器和 HAL 库理解 ADC 初始化和数据读取。

### 11. SPI 与 Flash

- 理解 SPI 通信协议和数据交换时序。
- 认识 W25Q32 Flash 的结构、读写指令和操作注意事项。
- 使用 GPIO 软件模拟 SPI 读写 Flash。
- 使用 STM32 SPI 外设读写 Flash。

### 12. 存储器、寄存器与 FSMC

- 了解常见存储器和 STM32 存储器结构。
- 理解存储器映射和寄存器映射。
- 了解 FSMC 的总线接口、NOR/PSRAM、NAND 和外设接口。
- 使用 FSMC 扩展外部 SRAM。
- 使用 FSMC 按 8080 时序控制 LCD，完成显示实验。

## 高级篇：物联网通信

### 1. CAN 通信

- 理解 CAN 物理层、协议层、数据帧、远程帧和总线仲裁。
- 了解 STM32 CAN 控制器、发送邮箱、接收 FIFO 和接收过滤器。
- 使用环回静默模式进行 CAN 测试。
- 实现一发一收的双节点 CAN 通信。
- 使用寄存器和 HAL 库分别完成 CAN 工程。

### 2. 以太网与 W5500

- 理解以太网、互联网、OSI 七层模型和 TCP/IP 四层模型。
- 认识 W5500 的硬件结构、特点和主控交互方式。
- 移植 W5500 官方库并完成 STM32 工程集成。
- 搭建基础以太网通信。
- 实现 TCP 服务端、TCP 客户端和 UDP 通信。
- 搭建简易 Web 服务器。

### 3. Wi-Fi 与 ESP32-C3

- 了解 Wi-Fi、WLAN、IEEE 802.11、AP、2.4 GHz 和 5 GHz 频段。
- 理解 Wi-Fi 信道、穿墙能力和常用网络术语。
- 认识 ESP32-C3 模块及其与 STM32 的连接方式。
- 使用 ESP-AT 固件和 AT 指令控制 Wi-Fi 模块。
- 实现 STM32 与 ESP32-C3 的串口交互。
- 使用 Wi-Fi 建立 TCP 通信。

### 4. Bluetooth LE

- 了解蓝牙的发展、技术类型和常见架构。
- 理解 BLE 协议栈中的 PHY、LL、HCI、GAP、ATT 和 GATT。
- 认识 BLE 角色、地址、广播、扫描和通信流程。
- 使用 ESP32-C3 实现蓝牙透传模式下的数据收发。

### 5. LoRa

- 了解常见无线通信协议和低功耗广域网。
- 理解 LoRa 的特点、应用场景和组网架构。
- 认识 E220-400M22S 模块、引脚和关键通信参数。
- 实现 LoRa 普通节点。
- 移植官方驱动并搭建 LoRa 网关。
- 验证节点到网关的数据传输。

## 扩展篇：系统级功能

### 1. 电源控制与低功耗

- 理解 STM32 电源框图、上电复位、掉电复位和可编程电压检测器（PVD）。
- 了解睡眠、停机和待机三种低功耗模式。
- 分别使用寄存器和 HAL 库实现低功耗案例。
- 关注唤醒源、时钟恢复和低功耗状态下的外设行为。

### 2. RTC 与备份域

- 了解 RTC 功能框图和掉电继续运行机制。
- 理解备份寄存器、侵入检测、RTC 校准和备份数据保存。
- 使用备份寄存器保存掉电期间需要保留的数据。
- 使用 RTC 闹钟唤醒待机模式。
- 实现掉电不丢失的实时时钟。

### 3. 看门狗

- 理解看门狗用于监测程序运行状态和恢复异常系统。
- 了解独立看门狗和窗口看门狗的工作方式。
- 对比两类看门狗的触发条件和使用场景。
- 使用独立看门狗完成异常复位案例。

### 4. HAL 工程与编译流程

- 分析 HAL 库目录结构和 STM32CubeMX 生成的工程。
- 理解 `startup_stm32f103xe.s`、`system_stm32f1xx.c`、`stm32f1xx_it.c`、`stm32f1xx_hal_conf.h` 和 `stm32f1xx_hal.c` 的作用。
- 理解 `HAL_Init()`、`SystemClock_Config()`、`MX_GPIO_Init()` 和 `MX_USART1_UART_Init()` 等初始化流程。
- 了解普通 C 源文件到可执行文件的过程。
- 了解 Keil MDK 的编译过程。
- 区分程序的静止状态和运行状态。

## 开发方式对比

| 方式 | 主要特点 | 学习重点 |
| --- | --- | --- |
| 寄存器开发 | 直接操作外设寄存器，接近芯片硬件 | 地址、位域、时序和参考手册 |
| HAL 库开发 | 使用 ST 提供的抽象接口，提高开发效率 | CubeMX 配置、回调、状态和生成代码 |
| 混合开发 | 在 HAL 工程中针对关键功能使用寄存器 | 抽象层边界、时序控制和可维护性 |

课件在多个案例中同时使用寄存器和 HAL 库实现，适合用于理解“硬件原理”和“工程效率”之间的关系。

## 推荐学习顺序

1. 完成基础篇中的 GPIO、时钟、HAL 和第一个下载运行工程。
2. 按 USART、I2C、SPI 的顺序学习常用片上通信接口。
3. 学习中断、定时器、DMA 和 ADC，建立事件驱动与数据搬运能力。
4. 学习存储器映射、FSMC 和 LCD，理解外部设备扩展。
5. 进入高级篇，依次学习 CAN、以太网、Wi-Fi、蓝牙和 LoRa。
6. 最后学习扩展篇中的低功耗、RTC、备份域、看门狗和 HAL 工程分析。
7. 每学习一个外设，分别记录硬件连接、时钟配置、寄存器或 HAL 配置、数据流和验证方法。
